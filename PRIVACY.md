# Privacy Policy

This policy describes builds made from this repository. Other distributions of Material Files may have different policies.

## No analytics or automatic crash reporting

The app includes no advertising, usage tracking, analytics SDKs or automatic crash reporting. It does not send file contents, device identifiers, usage events or diagnostic reports to the developers. No app account is required.

## Files and local settings

The app reads and changes files to carry out your file operations. Settings, saved server connections and thumbnail caches are stored on your device. Files remain in the local or remote storage locations you choose. Android system backup and device migration are supported, so app data may be backed up according to your device's system settings and backup provider.

Android can record local diagnostic logs when errors occur. The app does not automatically upload those logs. If you choose to include logs in a bug report, review them before sharing.

## Network features and other apps

Network access supports remote storage (including FTP, SFTP, SMB and WebDAV), local network discovery and the built-in FTP server. Servers you connect to can receive connection information, authentication credentials and files involved in your operations. Their data handling depends on the server you use.

When you open an external link or share a file with another app, that website or app handles the data under its own policy.

## Questions and changes

Changes to this policy are published in this repository. You can raise questions in the [project issue tracker](https://github.com/giturass/MaterialFiles/issues).
